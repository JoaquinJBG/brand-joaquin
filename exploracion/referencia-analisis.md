## Qué se repite en las dos

| Pieza | Portfolio | Pomodoro |
|---|---|---|
| Fondo | `#0b0b0b` | `#0b0b0b` |
| Texto | hueso `#ece9e1` | hueso `#ecebe6` |

| Líneas | `#2e2d2a`, finas | `#262626`, finas |
| Letra títulos | Archivo, mayúsculas gigantes | Syne / Inter Tight, números gigantes |
| Letra etiquetas | JetBrains Mono, mayúsculas pequeñas | mayúsculas pequeñas |
| Estructura | cuadrícula con líneas, esquinas rectas | igual |
| Secciones | numeradas (01, 02…) | numeradas (01, 02) |
| Sello | esfera de partículas animada | la misma esfera |

## El mecanismo

Pocos ingredientes, siempre los mismos y usados con disciplina: 3 colores, 2 letras, una forma de
colocar las cosas y un detalle propio (la esfera). La marca no depende de un logo.

## Qué evitar para no parecerse a la referencia

Si una propuesta para Joaquín cumple dos o más de estas, se cambia:

- negro + hueso + un solo naranja;
- etiquetas pequeñas en mayúsculas y monoespaciada;
- secciones numeradas 01/02/03;
- cuadrícula de líneas finas con esquinas rectas;
- esfera de partículas.
